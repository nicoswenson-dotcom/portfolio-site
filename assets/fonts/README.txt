Drop your font files here:

  dazzle-unicase.woff2     ← required for headers
  dazzle-unicase.woff      ← optional (older browser support)
  futura.woff2             ← required for body
  futura.woff              ← optional
  futura-italic.woff2      ← optional, for italics

Until these files exist, the site falls back to:
  Bungee  → for headers
  Jost    → for body (Jost is designed as a Futura alternative)

See ../../README.md for the two install paths (self-host vs. Adobe Fonts).
